WASD MoverMouse Mirar / dispararEspaço Pular
Use o direcional para andar e arraste a arena para mirar.

  • Teclado: WASD ou ↑/↓ para andar, ←/→ para mirar, Espaço para pular, F para disparar, R para recarregar e P para pausar.
  • Mouse: mova para mirar e clique para disparar. Se o cursor não travar, arraste para mirar.
  • Toque: use o direcional, arraste a arena para mirar e use os botões de ação.
